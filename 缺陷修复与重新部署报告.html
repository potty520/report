2.1 根因

后端实际字段前端期望字段影响

结果：页面新建任务 100% 失败；列表「年度/期数/开始日期/结束日期」4 列显示为空。

2.2 修复方案

在 API 层做双向映射，把字段差异收敛在一处，页面组件无需感知后端字段名。 文件：frontend2/src/services/api.ts

① 读取方向 —— 归一化补全

function normalizeTaskRow(x) {
  const belongTime = x.belongTime ?? '';
  // "2026-Q1" → year=2026, period="Q1"
  const yearFromBelong = /^\d{4}/.test(belongTime) ? Number(belongTime.slice(0,4)) : undefined;
  const periodFromBelong = belongTime.length > 4 ? belongTime.slice(5) : undefined;
  return {
    ...x,
    name: x.name ?? x.taskName,
    year: x.year ?? yearFromBelong,
    period: x.period ?? periodFromBelong ?? '',
    startDate: x.startDate ?? x.startTime ?? '',
    // fillDeadline 作为结束日期展示，截取日期部分
    endDate: x.endDate ?? (x.fillDeadline ? String(x.fillDeadline).slice(0,10) : ''),
    templateName: x.templateName ?? (x.templateId != null ? `模板#${x.templateId}` : ''),
  };
}

② 写入方向 —— 参数转换

export function toTaskPayload(data) {
  const belongTime = data.year != null
    ? (data.period ? `${data.year}-${data.period}` : String(data.year))
    : undefined;
  // 纯日期补 23:59:59，满足 LocalDateTime
  const fillDeadline = data.endDate
    ? (data.endDate.length === 10 ? `${data.endDate}T23:59:59` : data.endDate)
    : undefined;
  return {
    taskName: data.name,
    templateId: data.templateId,
    belongTime,
    fillDeadline,
    description: data.description,
  };
}

三、FIX-3：LocalDateTime 反序列化

3.1 根因

application-prod.yml 配置了 spring.jackson.date-format: yyyy-MM-dd HH:mm:ss， 但该配置只对 java.util.Date 生效，对 java.time.LocalDateTime 无效。 项目实体大量使用 LocalDateTime，Spring Boot 默认 JavaTimeModule 只认 ISO-8601。

3.2 修复方案

新增 backend/src/main/java/com/reportsys/config/JacksonConfig.java：
  • 注册 LocalDateTime / LocalDate / LocalTime 的序列化与反序列化器
  • 序列化统一输出 yyyy-MM-dd HH:mm:ss
  • 反序列化兼容三种格式（向后兼容，不破坏现有调用）： yyyy-MM-dd HH:mm:ss / yyyy-MM-dd / ISO-8601

3.3 修复验证

输入格式修复前修复后落库结果
