## 三、本轮新增（手册之外）

| 能力 | 说明 |
|---|---|
| 角色拆分 | 新增 `TEMPLATE_AUDITOR`、`TASK_MAKER`、`TASK_ASSIGNER`，与原 4 类共 7 类；脚本 `docs/report_2.2_roles.sql` |
| 5 类站内消息 | 模板审核结果、任务分派、部门审核通过、任务方审核通过/入库、补正发起 |
| 分派统计 | `GET /statistics/assign-stats`（分派人数/已填报/状态） |
| 补正次数统计 | `GET /statistics/correct-stats`（总数/进行中/已完成） |
| 填报页校验拦截 | 提交前调用 `/verify`，逐行错误弹窗并阻止提交 |

## 六、与原版 V2.3 的差异说明

| 项 | 原版 | 本系统 |
|---|---|---|
| 角色 | 5 类 | 7 类（新增超管与审核人员，制定/分派已拆分） |
| 登录 | 运维平台单点 | 自带登录 + 验证码 + 失败限流 |

| 报表核验 | 两步独立界面 | 提交前自动两步校验，逐行错误拦截 |
| 部署 | 双系统 | 单体（应用 + MySQL + nginx） |
