## 三、数据库变更（`docs/report_2.1_upgrade_features.sql`）

- 新增表 4 张：`rpt_task_return`、`rpt_template_display_config`、`rpt_import_check`、`rpt_correct_item`
- 新增列 10 个：`rpt_task.return_*`（4）、`rpt_task_data.no_update*`（2）、`rpt_quality_report.check_result`、`rpt_template_field.field_kind`、`rpt_template.materialize_type`、`sys_dept.is_fill_dept`
- 全部为 `ADD COLUMN` 带默认值 / `CREATE TABLE IF NOT EXISTS`，脚本幂等，可重复执行
- 存量回填：`sys_dept.is_fill_dept` 按"已被分派过的部门"置 1
